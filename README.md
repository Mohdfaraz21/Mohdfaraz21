### 💳 Offline Payment Settlement System

An offline payment settlement engine that simulates **UPI transaction routing over a Bluetooth-style mesh network**.

**Tech:** TypeScript, Node.js, Express.js, React, PostgreSQL, Prisma, Socket.io

* Designed a **multi-hop mesh routing architecture** for offline payment delivery and real-time network monitoring.
* Implemented **RSA-OAEP + AES-256-GCM** hybrid encryption, SHA-256 hashing, replay protection, and tamper detection.
* Engineered **exactly-once settlement** using idempotency claims, database constraints, and PostgreSQL **ACID transactions**.
* Validated concurrent duplicate deliveries with automated tests to prevent **double settlement**.

🔗 [GitHub Repository](https://github.com/Mohdfaraz21/SignalLess-UPI)
